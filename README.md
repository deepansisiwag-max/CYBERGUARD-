# 🛡️ CYBERGUARD
### Secure Login Activity Analyzer

## 📌 About the Project
CYBERGUARD is a beginner-friendly cybersecurity project developed to monitor and analyze login activities.

It helps identify suspicious login attempts by analyzing login records, IP addresses, and login status.

## 🎯 Objectives
- Monitor login activities.
- Record successful and failed login attempts.
- Analyze IP addresses.
- Identify suspicious login patterns.
- Display login activity through a dashboard.

## ⚙️ Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## 🚀 Features
- Live clock
- Login activity monitoring
- Login simulator
- IP address analysis
- Failed login tracking
- Dashboard with activity statistics
- Login activity visualization

## 💻 How to Run the Project

1. Download or clone this repository.
2. Install Python.
3. Install the required dependencies:

   pip install -r requirements.txt

4. Run the Flask application:

   python app.py

5. Open your browser and visit:

   http://127.0.0.1:5000
